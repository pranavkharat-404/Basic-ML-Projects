#  Movie Genre Classification

## Objective
Build a machine learning model to predict the genre of a movie based on its plot description using NLP techniques.

---

## Tech Stack
- Python
- Pandas, NumPy
- NLP (TF-IDF)
- Machine Learning (Logistic Regression, Naive Bayes, SVM)
- Matplotlib, Seaborn

---

## Features
- Data preprocessing (cleaning, stopword removal)
- Exploratory Data Analysis (EDA)
- TF-IDF vectorization
- Multi-class classification (27 genres)
- Model comparison (LR, NB, SVM)
- Confusion Matrix & visualization

---

## Results
- Logistic Regression Accuracy: ~58%
- SVM improves performance further
- Better performance on high-frequency genres (Drama, Documentary, Comedy)

---

## Dataset

Downloaded from Kaggle:
https://www.kaggle.com/datasets/hijest/genre-classification-dataset-imdb
